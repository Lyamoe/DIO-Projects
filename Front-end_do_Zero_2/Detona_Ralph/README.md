# Desafio 02: Criando um jogo inspirado em Detona Ralph

Projeto desenvolvido durante o curso da [DIO](https://www.dio.me/). O objetivo era aplicar os conhecimentos de linguagens web no projeto.  

## 🔧 Tecnologias
- **HTML5**
- **CSS3**
- **JavaScript**

## 🎨 Meu foco no projeto
- Ir além do desafio e fazer um **jogo divertido**.  
- Adicionar **features** extras.  
- Aprender o uso de **intervalos** em javascript.

👉 Pude aprender bastante com esse projeto, mudando a forma com que eu programava e adotando **boas práticas**.
