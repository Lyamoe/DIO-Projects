# Desafio 01: Criando sua primeira Landing Page com HTML e CSS  

Projeto desenvolvido durante o curso da [DIO](https://www.dio.me/). A proposta foi estilizar uma landing page a partir de um HTML base, tomando como referência este [exemplo](https://micheleambrosio.github.io/dio-trilha-css-desafio-01/).  

## 🔧 Tecnologias
- **HTML5**
- **CSS3**

## 🎨 Meu foco no projeto
- Criação de um **CSS mais próximo de um site real**.  
- Inclusão de **animações sutis de hover** para melhorar a interação.  
- Implementação de **responsividade** para diferentes dispositivos.  

---
👉 Esse projeto me ajudou a praticar conceitos de **estilização moderna** e **design responsivo**, essenciais no desenvolvimento web atual.
