# Desafio 01: Criando sua primeira Landing Page com HTML e CSS

Usando o HTML base fornecido pela DIO, a missão do matriculado no curso é de criar um CSS semelhante ao apresentado no [exemplo](https://micheleambrosio.github.io/dio-trilha-css-desafio-01/), embora esteja livre para outras modificações.

Meu foco neste projeto foi fazer um CSS mais próximo do que seria usado num site real, com pequenas animações de hovering e responsividade em diferentes dispositivos.
