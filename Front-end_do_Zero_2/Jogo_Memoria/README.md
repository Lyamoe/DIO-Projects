# Desafio 04: Um jogo da memória usando HTML, CSS e JS

Projeto desenvolvido durante o curso da [DIO](https://www.dio.me/). O desafio era de criar um jogo da memória 
utilizando os conhecimentos de HTML, CSS e JS adiquiridos no curso.  

## 🔧 Tecnologias
- **HTML5**
- **CSS3**
- **JavaScript**

## 🎨 Meu foco no projeto
- Aprender **animações avançadas** com CSS.  
- Adicionar **features** extras.  
- Praticar conhecimentos de JavaScript.

👉 Este projeto ainda está pendente de melhorias que adicionam algo diferente ao projeto!
